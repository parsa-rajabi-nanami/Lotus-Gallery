# معماری فرانت‌اند لوتوس

منبع: بخش‌های ۳ و ۵ `context.md`. تصمیم نهایی مطابق درخواست پروژه و انتهای کانتکس: **Vite + React (JSX) + Tailwind CSS + GSAP**. گزینه‌های Next.js و Framer Motion در بخش قدیمی کانتکس با این تصمیم جایگزین شده‌اند.

## استک و مرز مسئولیت‌ها

- کامپوننت‌ها ماژولار، قابل استفاده مجدد و مبتنی بر JSON باشند.
- GSAP مسئول Scroll Reveal، ورودهای متوالی و Parallax است؛ انیمیشن‌ها هنگام unmount پاک‌سازی شوند و `prefers-reduced-motion` رعایت شود.
- Three.js، React Three Fiber و Spline برای فاز بعدی اختیاری‌اند؛ رندر ۳۶۰ درجه، IOR پیشنهادی 2.417 و تغییر متریال طلا ایده‌های آینده‌اند، نه قابلیت‌های موجود.
- این مرحله آماده‌سازی داده، دارایی و مستندات است؛ هنوز اپ اجرایی، package.json یا وابستگی نصب‌شده‌ای وجود ندارد.

## درخت صفحه اصلی

ساختار صفحه فرانت‌اند باید دقیقاً طبق کامپوننت‌های زیر توسعه یابد:

1. **`<LiveTicker />`**: نوار بسیار باریک در بالاترین نقطه سایت (چسبان). نمایش قیمت لحظه‌ای: مثقال آبشده، طلای ۱۸ عیار، انس جهانی، سکه امامی و دلار تهران (شبیه تیکرهای بلومبرگ).
2. **`<Navigation />`**: هدر شیشه‌ای شفاف حاوی لوگوی لوتوس، لینک دسته‌بندی‌ها، و دکمه اوت‌لاین طلایی «رزرو مشاوره VIP».
3. **`<HeroCinematic />`**: سکشن تمام‌صفحه. تایپوگرافی درشت: "تجلی زیبایی در جدیدترین محصولات صنعت طلا و جواهر". تصویر پس‌زمینه تیره با حضور پررنگ انگشتر ۱ قیراطی GIA (کد ۱۱۴۳۳). دارای دو دکمه CTA: "کالکشن جدید" و "بازدید حضوری".
4. **`<ValuePropositions />`**: چهار باکس مینیمال برای معرفی ۴ مزیت رقابتی لوتوس (بدون مالیات، گارانتی مادام‌العمر، GIA، کارگاه اختصاصی).
5. **`<FlagshipBentoGrid />`**: حیاتی‌ترین بخش صفحه. یک ساختار شبکه‌ای (Bento Layout) برای نمایش ۴ پرچمدار اصلی (دیتای JSON در `src/data/products.json` آمده است). کارت‌ها باید شیشه‌ای و دارای بج‌های طلایی رنگ باشند.
6. **`<CollectionSlider />`**: اسلایدر دسته‌بندی‌های سایت بر اساس داده‌های قیمتی لوتوس:
* **سرویس‌های فاخر:** (از ۱.۲ تا ۵.۸ میلیارد تومان)
* **نیم‌ست‌های جواهری:** (از ۴۵۰ میلیون تا ۱.۵ میلیارد تومان)
* **حلقه‌های نامزدی:** (از ۲۵۰ میلیون تا ۱.۵ میلیارد تومان)
* **گوشواره‌های جواهری:** (از ۶۴۰ میلیون تا ۱.۳ میلیارد تومان)
* **آویز و گردنبند:** (از ۱۶۵ میلیون تا ۱.۳ میلیارد تومان)


7. **`<VideoShowcase />`**: پخش خودکار و صامت یک ویدیوی باکیفیت از درخشش سرویس الماس جیبسون (کد ۲۱۱۸۰) در پس‌زمینه تیره برای ایجاد حس لوکس بودن.
8. **`<KnowledgeBasePreview />`**: لینک به مقالات کلیدی سایت (جهت سئو): "۷ اشتباه رایج خرید سنگ قیمتی"، "محاسبه قیمت طلا"، "همه چیز درباره شاخص ۴C الماس".
9. **`<VIPConcierge />`**: یک فرم تاریک و شیک برای «رزرو زمان بازدید خصوصی» در شعبه بازار بزرگ (پاساژ چیت‌ساز). خروجی فرم باید مستقیماً کاربر را به واتساپ مدیریت (شماره ۰۹۳۶۳۷۹۳۱۱۰) هدایت کند.
10. **`<Footer />`**: آدرس دقیق، ساعت کاری (۸ تا ۲۱)، شماره تماس‌ها و نماد تجارت الکترونیک.

## قرارداد داده و دارایی

- کاتالوگ: `src/data/products.json`؛ کلید `sku` رشته است و شناسه پوشه هر محصول محسوب می‌شود.
- تصویر اصلی: `public/assets/products/<sku>/main.jpg`؛ تصویر دوم فقط اگر در منبع وجود داشته باشد: `alt.jpg`.
- URLها نسبت به ریشه سایت‌اند: `/assets/products/<sku>/main.jpg`. برای استقرار زیرمسیر در Vite از `import.meta.env.BASE_URL + product.image_url.replace(/^\//, '')` استفاده شود.
- `alt_image_url` اختیاری است؛ برای سه محصول فاقد تصویر دوم، تصویر ساختگی یا URL تکراری اضافه نشده است.
- فیلدهای `cut_grade`، `side_stones` و `color_clarity` نیز در همه محصولات موجود نیستند؛ کامپوننت‌ها نبود آن‌ها را مدیریت کنند.
- **ابهام واحد پول:** نام `price_irr` به ریال اشاره دارد ولی `price_formatted` همان مقدار را به تومان نشان می‌دهد. داده منبع بدون تبدیل حفظ شده؛ پیش از محاسبه، اتصال پرداخت یا تولید قیمت نمایشی، واحد واقعی باید تعیین شود.
- قیمت‌ها و مشخصات، snapshot کانتکس‌اند؛ API زنده یا سند مستقل تأیید گوهرها نیستند.
- گزارش فایل‌ها و URLهای مبدأ: `docs/assets-manifest.json`.
- فایل‌های برند در `src/assets/branding/` هستند. SVGها placeholder و فاقد اعتبار لوگو یا گواهی رسمی‌اند. تصاویر اصلی موجود در ریشه نیز در این پوشه کپی شده‌اند.
- ویدیو محصول ۲۱۱۸۰، بافت HDR، LUT، فایل فونت، نماد معتبر، API نرخ زنده و مدل‌های سه‌بعدی در منبع ارائه نشده‌اند. قابلیت‌های وابسته هنوز آماده اجرا نیستند.
- شماره مقصد مشاوره واتساپ پس از نرمال‌سازی: `989363793110`؛ اتصال فرم در مرحله توسعه انجام می‌شود.
