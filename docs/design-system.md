# سیستم طراحی لوتوس

منبع: بخش ۴ `context.md`.

### الف) لحن و کپی‌رایتینگ (Tone of Voice)
* **کلمات اکیداً ممنوعه:** «ارزان»، «تخفیف»، «حراج»، «فروش ویژه»، «خرید پستی».
* **کلمات و مفاهیم مطلوب:** «سرمایه‌گذاری ماندگار»، «ارزش‌آفرینی»، «آتلیه اختصاصی»، «شاهکار»، «تشریفات رزرو»، «کالکشن فاخر»، «گواهی اصالت».
* **لحن:** مشاوره‌دهنده، قاطع، شفاف، مینیمال و اشرافی.

### ب) تایپوگرافی (Typography)
* **فونت اصلی (زبان فارسی):** `Yekan Bakh` یا `Peyda`.
  * استفاده از اعداد فارسی استاندارد الزامی است.
  * وزن‌ها: Light (300) برای توضیحات، Regular (400) برای بدنه، SemiBold (600) برای عناوین.
* **فونت ثانویه (زبان انگلیسی و اعداد):** `Playfair Display` یا `Cinzel`.
  * کاربرد: درج قیمت‌ها به فرمت انگلیسی (مثلاً 1,500,000,000)، کدهای SKU، بج‌های GIA و نام لاتین کالکشن‌ها.

### ج) پیکربندی Tailwind (پالت Dark Studio)
مرجع اجرایی توکن‌ها: `tailwind.config.js` در ریشه پروژه.

| توکن | مقدار |
| --- | --- |
| black | `#0A0A0A` |
| charcoal | `#151515` |
| border | `#2A2A2A` |
| gold | `#D4AF37` |
| gold.light | `#F3E5AB` |
| gold.dark | `#AA882E` |
| rosegold | `#E0A899` |
| whitegold | `#E2E8F0` |

### د) قوانین تعاملات (Interaction Rules)

* **Glassmorphism:** کارت‌های محصولات و نویگیشن‌بار باید دارای `backdrop-blur-md` روی رنگ `bg-lotus-charcoal/50` باشند.
* **Hover States:** با رفتن موس روی محصولات، از ترانزیشن‌های کند (مثل `duration-700`) استفاده شود. تصویر محصول یک `scale-105` بسیار نامحسوس بگیرد و بوردر کارت به `border-lotus-gold/30` تغییر رنگ دهد.

## قواعد اجرایی

- جهت پیش‌فرض فارسی RTL است؛ SKU، نام لاتین و بج‌های انگلیسی در محدوده LTR نمایش داده شوند.
- متن و قیمت فارسی با اعداد فارسی نمایش داده شوند؛ فرمت انگلیسی فقط در محدوده صریحاً انگلیسی استفاده شود. واحد قیمت تا رفع ابهام کاتالوگ تبدیل نشود.
- خانواده فارسی: Yekan Bakh سپس Peyda؛ خانواده لاتین: Playfair Display سپس Cinzel. فایل فونت و مجوز آن هنوز تأمین نشده؛ تعریف خانواده به معنی بارگذاری فونت نیست.
- گرادیان‌های `bg-gold-gradient` و `bg-glass-panel` و سایه‌های `shadow-gold-glow` و `shadow-glass-inset` در کانفیگ تعریف شده‌اند.
- کانفیگ CommonJS حاضر با الگوی Tailwind 3 سازگار است. اگر Tailwind 4 انتخاب شد، فایل JS باید در CSS با `@config "../tailwind.config.js";` (نسبت به محل CSS) صریحاً معرفی شود. با افزودن `type: module`، فایل را به ESM تبدیل کنید یا پسوند `.cjs` بدهید و ارجاعات را هماهنگ کنید.
- وضعیت focus قابل مشاهده، کنتراست خوانا، تعامل لمسی و کاهش حرکت در توسعه کامپوننت‌ها رعایت شوند.
